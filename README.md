# Python Data Analysis and REST APIs

## Project Overview

This project is a Python Data Analysis Application developed as part of the Python Programming Internship.

The project demonstrates data loading, data cleaning, data analysis, data manipulation, data visualization, and REST API consumption using Python.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Requests
- JSON
- Google Colab

## Project Features

- Load and manage student performance data
- Create and work with Pandas DataFrames
- Handle missing values
- Remove duplicate records
- Calculate average, highest, and lowest marks
- Perform department-wise data analysis
- Identify top-performing students
- Filter students based on marks
- Visualize data using Matplotlib
- Visualize data using Seaborn
- Consume a REST API using HTTP requests
- Process JSON API responses
- Generate a student performance report
- Save cleaned data as a CSV file

## Dataset

The project uses a student performance dataset containing:

- Student ID
- Name
- Department
- Age
- Marks
- Attendance

The dataset is cleaned before performing analysis.

## REST API

The project consumes a REST API and processes the JSON response using Python.

The API data is converted into a Pandas DataFrame for easier analysis and display.

## Project Files

- `Python_Data_Analysis_APIs.ipynb` — Google Colab notebook containing the complete project

- `cleaned_student_performance.csv` — Cleaned dataset

The project generates:
